• 3 mod(s) change the game's code in 2 place(s)
  Carry On (1), Vintage Doctor (1), Doctor Example (1)
  Mods patch the game's own code where it offers no other way in. It is normal, but it is also what breaks first when the game updates, and two mods patching the same place can get in each other's way.
• Doctor Example and Vintage Doctor change the same 1 place(s) in the game's code
  SelfTest.SharedPlace: Doctor Example (runs after it), Vintage Doctor (runs before it)
  Each line is one piece of the game's code and what each mod does to it. Mods that only run something before or after the game's code usually get along. It goes wrong when one of them stops the game's code from running, which the other counted on, or when both rewrite it. If something these mods have to do with misbehaves, these are the places to tell their authors about.

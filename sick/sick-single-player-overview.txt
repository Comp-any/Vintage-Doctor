  doctorsick:hot-warning: </font> while <strong> is still open, at character 18: <strong>Hot!</font> Don't touch
  The game reads < and > in texts (chat, item descriptions, tooltips, the handbook) as formatting tags. A > on its own, or a closing tag that doesn't match, makes it write an error every time the text is shown; the text is usually still shown. The error never says whose text it was, so the doctor reads every mod's texts the way the game does and finds the ones that make that very error.

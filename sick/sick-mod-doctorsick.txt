⚠ Doctor Sick's texts have formatting tags out of place: 2 error(s) about them in the log this session
  doctorsick:lever-help: a > with no < before it, at character 16: Pull the lever -> the gate opens
  doctorsick:hot-warning: </font> while <strong> is still open, at character 18: <strong>Hot!</font> Don't touch
  The game reads < and > in texts (chat, item descriptions, tooltips, the handbook) as formatting tags. A > on its own, or a closing tag that doesn't match, makes it write an error every time the text is shown; the text is usually still shown. The error never says whose text it was, so the doctor reads every mod's texts the way the game does and finds the ones that make that very error. The whole text is also in server-debug.log, on the line after each error.
  → Tell Doctor Sick's author which texts these are (the names above are their keys in the mod's lang file): a > that isn't part of a tag has to be written &gt;, and a < as &lt;.
